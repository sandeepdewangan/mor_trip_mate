# Mor Trip Mate

Open Source Project

Mor Trip Mate is a cross-platform travel planning app available on iOS, Android, Desktop (Mac-os, Windows, Linux), and Web. It helps you effortlessly create, organize, and manage your trip itineraries in one place. Mor Trip Mate makes planning your journey simple, smart, and stress-free.
